# Incident Report: IR-005
## Technique: Windows Credential Manager Enumeration (T1555.004)

### Executive Summary
A high-severity credential access alert fired on `WIN11-TARGET` following the execution of `cmdkey.exe /list`. Threat actors enumerate cached credentials stored in Windows Credential Manager to harvest domain tokens, web credentials, and network share authentication details.

### Incident Overview
- **Incident ID**: IR-005
- **Severity**: High (Level 14)
- **Target Host**: `WIN11-TARGET` (IP: `10.10.10.4`)
- **Detection Engine**: Wazuh SIEM + Sysmon Integration
- **Custom Rule ID**: `100104`
- **MITRE ATT&CK Mapping**: Credential Access / Credentials from Password Stores: Windows Credential Manager (`T1555.004`)

---

### Threat Details & Execution Vector

#### Attack Command
```cmd
cmdkey.exe /list
```

#### Simulated Behavior
Execution of native `cmdkey.exe` tool with the `/list` parameter to query and list stored Windows credentials without requiring system-level elevation.

---

### Telemetry & Log Evidence

- **Log Source**: `Microsoft-Windows-Sysmon/Operational`
- **Sysmon Event ID**: `1` (Process Creation)
- **Image**: `C:\Windows\System32\cmdkey.exe`
- **CommandLine**: `cmdkey.exe /list`
- **User Context**: `WIN11-TARGET\SOCAdmin`

---

### Detection Logic & Rule Configuration

Custom Rule `100104` monitors process command lines matching `cmdkey.*\/list`:

```xml
<rule id="100104" level="14">
  <if_group>windows</if_group>
  <field name="win.eventdata.commandLine" type="pcre2">(?i)cmdkey.*\/list</field>
  <description>Custom Detection: Saved Credentials Enumeration via cmdkey.exe (Atomic Red Team - T1555.004)</description>
  <mitre>
    <id>T1555.004</id>
  </mitre>
  <group>attack,credential_access,custom_detection,</group>
</rule>
```

---

### Response & Containment Recommendations

1. **Credential Rotation**: Immediately rotate passwords and access tokens for any accounts listed in Windows Credential Manager on the target host.
2. **LAPS Deployment**: Enforce Windows Local Administrator Password Solution (LAPS) to prevent shared local admin password reuse.
3. **Disable Saved Credentials**: Enforce Group Policy Objects (GPOs) to disable domain credential caching where not strictly required.
